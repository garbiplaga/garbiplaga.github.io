# Garbiplaga

Web corporativa de **Garbiplaga** — sanidad ambiental y control de plagas para hostelería en Donostia y Gipuzkoa.

## Publicación

El sitio se publica con GitHub Pages desde la rama `main` (raíz):

https://polkasansebastian.github.io/garbiplaga/

## Estructura

```
index.html      Página principal (one-page: servicios, método, planes, FAQ)
styles.css      Hoja de estilos
assets/         Logo e imágenes
```

## Flujo de trabajo

El diseño se mantiene en el canvas de Claude Design ("Mejora web Garbiplaga").
Cada versión aprobada se exporta a HTML estático y se sube a este repositorio.
